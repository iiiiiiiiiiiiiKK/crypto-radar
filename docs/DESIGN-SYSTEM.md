# Crypto Radar 2.0 — 设计系统

**「赛博 Meme 终端 + 像素游戏 HUD + 互联网漫画」**

三种语汇并存，但各有严格用途，混用就会变成噪音。

| 语汇 | 用在哪里 | 规则 |
| --- | --- | --- |
| 赛博终端 | 面板、表格、数字 | 冷静、高密度、等宽数字、极细边框 |
| 像素 HUD | 标题、名次、状态徽章 | 切角（clip-path）、硬阴影、字距加宽 |
| 互联网漫画 | 贴纸、事件卡 | 描边、轻微旋转（-1.5deg）、单色 |

## 令牌

所有颜色只以 CSS 变量出现，组件内不允许裸十六进制值。

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--cr-bg` | `#07080d` | 页面底色（偏蓝的黑，荧光色才有对比） |
| `--cr-panel` | `#0e1018` | 主面板 |
| `--cr-panel-2` | `#141826` | 次级面板 / 控件底 |
| `--cr-line` | `#232a3d` | 边框 |
| `--cr-accent` | `#39ff88` | 荧光绿：强调、选中、关键操作 |
| `--cr-up` | `#39ff88` | 上涨（与 accent 同色，语义不同） |
| `--cr-down` | `#ff3b6b` | 下跌 / 警报红 |
| `--cr-voltage` | `#b14cff` | 电光紫：异动、次要强调 |
| `--cr-warn` | `#ffe94a` | 亮黄：警告、名次第一 |

**语义色不随主题变化**：无论换成什么主题，涨永远是绿、跌永远是红，避免误读。

## 主题

主题只替换强调色，通过 `<html data-theme>` 生效：

- `neon`（默认）荧光绿
- `voltage` 电光紫
- `alarm` 警报黄

## 字体

| 场景 | 字体 | 说明 |
| --- | --- | --- |
| 数字 / 价格 | `--cr-font-mono` | JetBrains Mono 回退到系统等宽，保证小数位对齐 |
| 正文 | `--cr-font-sans` | Inter → 系统字体 → 苹方 |
| 标题 / 徽章 | `--cr-font-pixel` | Courier New + 字距 0.14em + 双色硬阴影，做出点阵感 |

不引入外部字体文件：离线可用、无第三方请求、不增加体积。

## 组件类

| 类名 | 用途 |
| --- | --- |
| `.cr-panel` | 切角面板（8px 切角，替代大圆角卡片） |
| `.hud-panel` | 首屏核心区块：10px 切角 + 渐变底 |
| `.hud-corner` | 四角括号装饰 |
| `.scanlines` | CRT 扫描线叠加（透明度 0.5，不干扰阅读） |
| `.pixel-title` | 像素标题 |
| `.pixel-label` | 像素小标签（10px，字距 0.18em） |
| `.sticker` | 漫画贴纸（描边 + 轻微旋转） |
| `.rank-badge` | 名次牌（金/银/铜 + 阶梯阴影） |
| `.glitch` | 低频故障动画（2.6s 内仅 3 帧位移，不刺眼） |

## 动效规范

| 动效 | 时长 | 用途 |
| --- | --- | --- |
| 价格闪烁 | 700ms | 价格变动（涨绿跌红，透明度渐隐） |
| 面板淡入 | 180ms | 页面/弹层出现 |
| 故障抖动 | 2.6s 循环，仅 3 帧位移 | 品牌标识，绝不用在数据上 |
| 连接脉冲 | 1.6s | 断线/重连状态 |

触控目标 ≥ 32px，底部导航 ≥ 48px（含安全区）。

## 禁止事项

- 不用通用 SaaS 仪表盘模板、大圆角卡片、无意义渐变、满屏霓虹
- 不用装饰性图表冒充真实行情
- 不让动效遮挡 K 线或数字
- 不在数据区域使用旋转/抖动
